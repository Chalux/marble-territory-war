# 动态分界、护盾与边缘汇流（2026-11-19）

## 半径分界

分界值由固定 256 改为 `256 × 2^(T / RadiusPivotDoublingSeconds)`，默认每 120 秒翻倍，连续增长。开局 256，2 分钟 512，4 分钟 1024，10 分钟 8192；新对局恢复 256。

计算直接使用对数分界 `pivot = 8 + T / max(1, RadiusPivotDoublingSeconds)`，半径增长项为 `pivot × (log2(max(1, value)) / pivot)^RadiusValueExponent`。保留原基础半径、最小半径、质量公式和时间衰减。新分界同时影响可见尺寸和碰撞。

新轨迹在 48 球拥挤回归中暴露了斜升降挡板直接修改位置、可能将大球推出侧墙的问题。挡板位移改为经过既有 CorrectPosition 扫掠碰撞，修复后拥挤检查通过；失败时输出首个越界状态便于后续定位。

## 动画

- 领土液体褶皱限制在距离边界约 16 逻辑像素以内，内部改为平静底色。
- 内部以不同旋向、变化螺距和低频扰动生成断续细流。光包沿半径减小方向传播，表现向对应阵营根据地吸入；不是整个画面固定角速度旋转。
- 装饰粒子优先从归属边缘生成，采用随机旋转幅度、相位和寿命的收缩螺旋路径；路径只在本阵营地块内显示，保留 P 粒子开关。
- 护盾加入移动高光、反向光带、呼吸亮度、向外传播的壳内波纹。护盾值增减驱动衰减脉冲，四方相位错开。光效在实际球壳内运动，未修改护盾碰撞半径。
- 所有动画使用模拟时钟，暂停不推进；重开或替换模拟会清理脉冲历史。
