# 第六轮视觉对照

2026-11-13。对照本地完整参考视频，使用 `detail-5.png`、`detail-720.png`，并重新提取视频 300 秒原始帧 `reference-300s.png`。

## 修改

- 盘面使用连续圆角距离场材质，重建多层金属倒角、凹槽、内侧阴影、深灰底色和 64 单位网格。旧外框节点保留但隐藏；碰撞墙的坐标没有改变。
- 碰撞钉改为解析同心金属环与球面高光材质，减少缩放后的多边形感。
- 开启 2D MSAA 4×，降低轨道、倍率圆环和斜边的锯齿。轨道高光线同步减细、降低亮度。
- 领土使用多尺度坐标扰动生成不规则流动褶皱，增强饱和渐变、减弱白色边框，减少规则放射条纹。领土仍只在模拟归属覆盖范围内显示。
- 护盾采用更宽的柔和亮边、较暗球心、更克制的干涉细线和更多星点；延长装饰粒子的可见曲线。
- 四侧经验栏分离彩色百分比与灰色完整数值，补充充能升级、100% 标记；移动弹珠使用整数 K/M 简写以适应球体宽度。

没有修改 `src/Simulation/`、默认配置、倍率槽入口、升降挡板或碰撞规则。

## 验证

- `dotnet build Demo.csproj --no-restore`：最终版本 0 警告、0 错误。
- `--self-test`：210 项通过；600 秒弹珠模拟 759 次倍率、214 次兑换；300 秒联动重放两遍为 shots=11337、territory=43083、upgrades=7。自检在场景及表现绑定修改后执行，之后只调整了材质参数、抗锯齿和弹珠数字格式。
- D3D12 / Mobile / GT 1030 真实渲染截图：`visual-v6-90s.png`、`visual-v6-300s.png`。修改前同种子 300 秒截图：`visual-v6-before-300s.png`。
- 最终独立运行的 300 帧基准：平均 18.236ms、P95 20.83ms、主循环 CPU 平均 1.222ms。数据为 `visual-v6-benchmark.json`。该基准在 90 秒预推进后测量，结束时没有活跃射弹或大球，不能推断后期密集交火帧率；不把历史机器状态不同的测试作为严格 A/B。
- 未发现场景解析、C# 或 Shader 编译错误。运行日志仍有沙箱导致的用户日志目录、系统证书及 Shader 缓存写入错误，截图和基准均正常完成。

## 仍有差异

目前是参考风格的实时重建，并非逐帧复现：现有对局的领土形状、粒子发射量、护盾数值及时间进度与视频不同。视觉流纹来自程序材质和独立装饰粒子，尚不等于参考的完整粒子流场；216×208 的逻辑归属网格也限制了边界精度。保留了此前调整过的倍率槽与挡板尺寸，因此盘面中部几何也没有恢复成视频原尺寸。
