# 涂色边界平滑修正

2026-11-13。针对射弹涂色呈方块拼接、浅角度色带呈阶梯的问题。

## 修正

原先直接插值 216×208 的四通道归属颜色，即使增加抗锯齿，5 单位格子形成的阶梯仍然存在。现在由 `VisualTerritoryContour` 根据归属生成四通道近似有符号距离场，再沿轮廓切线方向平滑，Shader 用三次插值重建连续边界。抗锯齿宽度随屏幕像素变化；亮边也从距离场生成。

切线来自局部梯度结构张量，因此细色带两侧相反的法线不会互相抵消。平滑沿色带延伸方向进行，降低缩窄细线的风险；已占领单格的中心保留内部距离，避免小色点直接消失。外侧不再强行贴合每个格子，允许显示轮廓在边界附近平滑移动。逻辑归属、面积、涂色消耗、经验及碰撞均未修改。

距离场沿用原有的约 14Hz 上传限制及重置失效机制；Shader 对空白区域跳过后续流纹、颜色和星点计算。

## 验证

- 构建：0 警告、0 错误。
- 自检：220 项通过，包含 10 项新增轮廓检查，覆盖空场、全场、单格色点、细斜线连续性、阵营一致性、输入不变、确定性及重置。
- 合成浅角度直线的边界位置标准差：1.451 → 0.233 逻辑像素，约减少 84%。该指标测的是指定直线样本，不能代表任意形状。
- 联动重放保持 shots=11337、territory=43083、upgrades=7；600 秒弹珠模拟保持 759 次倍率、214 次兑换。
- 实际截图：`smooth-contour-90s.png`、`smooth-contour-300s.png`。局部 2× 最近邻放大对比：`smooth-contour-comparison.png`（左旧右新）。检查了浅角度细线和大面积多阵营交界。
- 最终 300 帧基准平均 21.690ms、P95 26.922ms、主循环 CPU 平均 4.494ms，结束时 192 发射弹、1 个大球。该基准按真实时间推进，和此前基准结束战况不同，不是固定状态的严格性能 A/B；距离场重建确实增加了 CPU 工作。详见 `smooth-contour-benchmark.json`。
- 无场景解析、C# 或 Shader 编译错误；仍有环境用户日志、证书和 Shader 缓存写入提示。

显示边界是原逻辑格子的平滑拟合，不保证显示像素面积与逐格计费面积完全重合；计费继续使用未修改的原始归属数据。
