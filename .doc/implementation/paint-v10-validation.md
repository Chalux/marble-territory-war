# 参考风格流体与新涂色高亮（2026-11-19）

本轮重新查看本地参考图 `../参考图/8e8c0f9a-10ed-499c-9914-ff40fd1fdd2d.png` 和视频抽帧 `../analysis/detail-720.png`。前者主要提供整体视觉，后者显示饱和推进亮部、雾状叠色和细密纹理。没有宣称逐像素复刻。

## 修改

- 将分离的螺旋亮丝改成多尺度柔和色带与细粒纹理；保留朝对应根据地汇入的弯曲方向，降低周期条纹的存在感。
- 成熟领土保持较暗、平静的底色；较强的流体层出现在边缘窄带和刚涂色区域。细亮边弱化，减少硬质霓虹描边感。
- 每个逻辑格记录最近一次归属变更版本，表现层记录对应模拟时间。中立地首次占领、敌色覆盖和夺回都会点亮；同色重复涂色不刷新时间。同一步 A→B→A 仍能捕获变更。
- 高亮附加量按 `exp(-age / 1.6)` 回落，约 5 秒后剩余 4.4%；成熟底色继续显示。shader 的 `paint_fade_seconds` 可调整衰减速度。
- GPU 对邻格的亮度插值，而不是直接对新旧时间戳插值，避免旧格或未涂色格让新亮边突然消失。四个阵营通道分别保存，换色清除旧色高亮。
- 高亮独立于粒子开关，以模拟时间计时；暂停冻结，重开及换模拟清除历史。新增格版本仅供观察，不参与预算、伤害或归属决策。
