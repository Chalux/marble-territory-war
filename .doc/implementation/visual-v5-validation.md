# 第五轮视觉迭代：画质优先

2026-11-12。按本轮用户要求暂不考虑性能，未运行性能基准，也没有因帧率压缩新增特效。

## 画面变化

- 新增独立的射弹运动方向纹理：记录武器在已占领区域的运动方向和最近经过时间，驱动细丝走向与局部新鲜亮度。领土材质增加九点覆盖率重建、深浅色带、边缘高亮与更密的闪烁微光。
- 新增预置 `TerritoryFlow` 节点，最多保留 8192 个装饰粒子。粒子从对应阵营已占领的格子出发，沿三次贝塞尔路径汇入据点；每个粒子使用渐亮长尾和高亮粒子头。粒子采用独立随机序列与模拟时钟，暂停会冻结，重置会清空。
- 普通射弹的历史轨迹从 1.4 秒延长到 3.6 秒，历史容量从 8192 段扩展为 65536 段；绘制细芯与外围光晕，保留更密集的交错轨迹。
- 新增 49 点亮部辉光后处理，在高亮边缘和粒子周围扩散光。针对首轮实机截图的大片黄/绿发白问题，降低色带内部与粒子尾迹亮度，并抑制已经很亮的像素继续增亮。
- 护盾加入球面流光、干涉细纹和更清晰的星点；大球加入柔光外晕并随球径调整数字字号。
- 弹珠记录真实运动历史，高数值球带碎光尾迹，小球采用短拖迹；盘面补充切角金属外框。
- 截图工具支持小数秒与 `--capture-reset`，用于检查动画推进和重置一致性。

模拟代码、默认配置、碰撞与领土计费规则均未修改。粒子、方向纹理和辉光不会反馈到火力、经验或领土归属。所有新增节点保存在磁盘场景中。

## 边界

这轮强化了粒子密度、辉光和运动材质，不声称与参考逐帧一致。领土逻辑仍为 216×208，窄色带与边缘保留原模拟形成的形状；新方向纹理和装饰粒子不是参考的完整流体算法。参考中的同一秒数也不会对应本工程相同的战况。
