# 第四轮视觉复刻检查

日期：2026-11-12。参考为 `.doc/analysis/detail-5.png` 与 `detail-720.png`，上轮基线为 `dense-fire-90s.png`。

## 本轮调整

- 领土从等距径向条纹改为多尺度扰动的流动明暗、稀疏细丝与漂浮亮点。采用无三角函数哈希，消除本机 D3D12 实测中出现的块状纹理不连续。
- 护盾加深玻璃暗心、突出球壳亮边、高光和边缘干涉细线。场景绘制顺序变为领土/轨迹 → 护盾 → 核心与数字，解决轨迹直接覆盖护盾的问题。核心绘制脚本挂在已有据点节点上。
- 射弹保留原来的碰撞与涂色尺寸；视觉用细亮芯和按真实半径展开的柔光，减弱白色圆点组成的珠链感。
- 据点读数改为盾牌/机枪矢量图标，百万以下带千分位，零值为 `0.00`；数字使用粗体系统字体。能力栏增加五类图标，倍率槽长数字自动缩小。
- 发射器、碰撞钉增加金属渐变和刻度；较大弹珠的数值移至球心，补充彩色球面与弧形高光。经验轨道的刻度方向与填充方向对齐参考。
- 据点细丝与微粒按阵营批量绘制，替代逐条折线与逐个圆点。仍然没有运行时创建节点。

没有修改模拟代码、配置、碰撞几何、领土计费网格或随机数源。

## 验证

- `dotnet build Demo.csproj --no-restore`：0 警告、0 错误。
- `--self-test`：119 项通过；600 秒弹珠模拟 811 次倍率、158 次兑换。300 秒联动重放两遍：shots=4026、territory=44928、upgrades=3，与上轮一致。
- 1440×810、D3D12 / GT 1030 的真实画面检查：`visual-v4-30s.png`、`visual-v4-90s.png`。期间修正了纹理块状折痕、护盾遮挡层级、倍率槽长数字溢出问题。
- 90 秒预推进、30 帧暖机、300 帧动态采样：平均 34.43ms（约 29.0 FPS），P95 49.36ms，主循环 CPU 平均 4.76ms。见 `visual-v4-benchmark.json`。
- 批处理前的本轮采样为 48.68ms / P95 75.66ms，见 `visual-v4-before-batching.json`。两个采样过程中模拟继续推进，结束时射弹数分别为 407 与 240，不能将全部差异归因于绘制优化。该结果也不代表已经达到 60 FPS。
- 运行仍有沙箱系统证书读取和 Shader 缓存写入提示；实际截图、场景加载、Shader 渲染与测试正常结束。

## 尚未等同参考的部分

领土仍由 216×208 的逻辑网格驱动，近看存在阶梯；流动纹理为程序化材质，并不是参考中长时间积累的高密度粒子流场。参考与本工程的玩法参数和初始护盾存在差异，同一秒数不会产生相同色块与实体分布。本轮是材质、层级和界面细节的逼近，未达到逐像素或逐帧一比一。
