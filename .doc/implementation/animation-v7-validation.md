## 实现

- 机枪：38 单位柔光尾迹、24 单位亮芯，0.45 秒历史残留。
- 风暴：每枚射弹带横向弧形光锋，弹群汇成扫光；取消风暴的长历史线，保留实际涂色。
- 狙击：100 单位柔光、72 单位高亮芯、十字亮头。实际支付涂色费用时写入只供表现使用的时间戳，驱动 0.18 秒衰减、9Hz 亮头脉冲；8 个粒子沿交错椭圆反向环绕。己方地块不触发涂色闪光，池槽复用清除旧闪光。
- 狙击碎片：较短尾迹和亮头；大球保持暗心亮边球体；护盾保持球壳表现。
- 背景粒子缩短拖尾、加速汇入据点，移除固定绕据点的装饰曲线，减轻规则线团感。
- `H` 显示控制面板，使用“粒子效果 [P]”按钮；也可直接按 `P`。统一开关领土汇流粒子、领土/护盾星点、狙击环绕粒子和高值弹珠碎光。射弹主体、拖尾、扫光和涂色闪光仍可辨认。
- 动画使用模拟时钟；粒子开关只控制渲染，不改变玩法随机源、预算和运动。运行中重开保留当前开关选择；重新启动默认开启，也可使用 `--no-particles`。
- 尾迹继续按墙面反射；扫光、亮芯和环绕轨迹按线宽及抗锯齿余量裁切到战场内。

## 与一比一的距离

本轮完成能力动画区分和统一粒子开关，未达到逐帧一比一。参考的领土形状、百万像素级流场、粒子密度和整体明暗仍有差异；现有规则与参考对局也不是同一时间线。视频是效果与边界验证，不能当作逐像素一致性证据。
