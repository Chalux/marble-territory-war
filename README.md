## 运行

打开 `project.godot`，完成 C# 构建后按 **F5**。主场景为 `resource/scenes/Main.tscn`。逻辑画布 1920×1080，默认窗口 1440×810，窗口缩放不改变模拟结果。

| 操作 | 功能 |
| --- | --- |
| H | 显示 / 隐藏控制与信息面板；默认使用参考画面的纯净观战布局 |
| 鼠标移至战场底部中央 | 临时显示控制面板 |
| 空格 / 暂停按钮 | 暂停或继续两盘、经验、武器飞行和终盘计时 |
| Tab / 倍速按钮 | 1、2、4、8 倍速 |
| R / 重置按钮 | 相同种子重新开始 |
| 换种子新对局 | 使用新种子重新开始 |
| 查看战报 | 结束后重新打开统计界面 |
| 导出 JSON 报告 | 保存参数、结果、统计和完整兑换日志到 Godot 用户数据目录的 `reports/` |

报告导出成功后会显示实际文件路径；失败时会显示错误，不会伪报成功。

## 已实现玩法

- **弹珠循环**：每色三球、初值 1。×2/×4/×8 槽保留 ID 和球值回流；七格能力栏（风暴、机枪、护盾、大球、霰弹、狙击、护盾副本）向右循环，能力兑换后原球重置为 1。半径和质量随整局时间、球值变化；中央使用固定升力而非硬门槛。
- **盘面碰撞**：槽壁、槽底、侧壁、碰撞钉与显示使用同一几何；连续扫掠检测包含线段端点，球间位置分离也受墙体约束，避免穿漏。
- **风暴**：圆周发射，默认每波最多 192 发、最多 5 波；更高预算分摊到单弹。容量不足时保留整波等待。
- **机枪**：持续消耗当前储量发射，每发成本随储量增长；方向跟随据点旋转。池满不扣储量，淘汰后清空机枪。
- **霰弹**：兑换后把本次球值全额装进一波扇形弹丸，默认 24 发、基准扩散 ±12°；每发再叠加随机角度偏移、随机发射距离和 ±12% 速度抖动，形成前后错落的不规则弹幕。不使用储量、不分波，容量不足时整波等待。弹丸沿用机枪射弹的外观与碰撞密度。
- **护盾**：护盾值决定碰撞半径；显示球壳用 `ShieldRadiusEaseSeconds` 缓动到目标半径，碰撞与伤害仍按真实护盾值即时结算。己弹穿过；敌弹等值扣盾；若护盾被打破，多余数值保留并继续向前，可继续命中后方据点或大球。能力栏在狙击与风暴之间重复出现一格护盾。
- **大球**：独立位置、速度、质量、半径和数值。己弹增值、敌弹扣值，两者命中后均消失并施加推力；归零立即销毁。同阵营大球只反弹且不扣值（数值下降来自沿路径涂色或敌方攻击），敌对大球每次新接触双方各扣碰撞前较小值的 80%。敌盾接触转移 `min(0.8 × 球值, 盾值)` 并反弹，持续接触不重复扣值。数值达到 1B 后永久坍缩为中子星：半径压缩到 7，并对所有射弹与大球施加朝向星体的引力（数值越大引力越强，星体自身跳过自引力）。射弹摧毁大球时保留溢出值继续飞行。
- **狙击**：兑换即产生独立实体。沿前进路径计算削盾所需半径，保留初值 20% 作为裂解预算；预算阈值触发一次裂解，不再按时间失效。盾触发沿反弹方向，其余沿前进方向；碎片守恒分配剩余数值，不递归裂解，也不会超时消失。
- **射弹拦截**：不同阵营的射弹相遇时按较小值互相抵消：数值相等则同时消失，较大者保留差值继续飞行；同阵营射弹仍可重叠穿过。拦截与撞墙、护盾、大球、据点按实际碰撞时间统一排序。
- **领土与经验**：普通射弹与狙击碎片命中首个非己方格子时立即销毁，并按剩余数值向四周溅射涂色（每格成本 8，随局内时间增长）；大球与狙击主体沿路径连续涂色。面积乘时间积累经验，阈值 `56000 × (level + 2)`，升级保留超额经验并新增初值 1 的弹珠。
- **复活与亡语**：每色一次复活，牺牲最大值弹珠（同值取较小 ID），降一级并保留经验比例。再败后聚合剩余弹珠；亡语在护盾/机枪区反弹，只可兑换风暴、大球或狙击，兑换后消失。已发出的攻击实体不随阵营淘汰被删除。
- **终盘**：等待亡语完成，且存活据点与在场/待生成的大球最多属于同一阵营后，继续模拟 15 秒。残留普通射弹不阻止终盘。倒计时开始后不重置；最终按面积选出胜者，已淘汰阵营仍参与，同面积并列获胜。
- **统计**：对局总览、火力战报、六项实际指标；保留全局兑换日志。粒子只负责视觉，不参与任何数值、碰撞或胜负。

## 容量和实现约定

弹珠逻辑容量 128、大球池 64、射弹池 2048。弹珠盘的边框、网格、钉子、轨道、倍率槽、挡板、发射器和能力栏均保存在 `PinballBoard.tscn` 中，使用真实的 Polygon2D、Line2D、Label 和容器节点；钉子、倍率槽分别复用 `PinballPeg.tscn`、`PinballPocket.tscn`，运行时仅更新动画和读数。盘面不再使用脚本绘制。

弹珠容器 `Balls` 在场景中为空；弹珠进入 Flying 时按需实例化 `Ball.tscn`，回流、牺牲、消失或重开时移除并释放显示节点，等待中的弹珠只保留模拟数据。大球显示节点仍预置，普通射弹仍批绘制。满池奖励与火力保留到队列，视觉拖尾不改变实体状态。

碰撞继续使用固定步长的自定义扫掠模拟。调整盘面的钉子、轨道或倍率槽布局时，应同步 `PinballGeometry.cs` / `PinballSimulation.Pegs` 中的碰撞数据；`--board-test` 会检查两者一致性及动态弹珠生命周期。

未在参考规则中给出精确公式的部分采用以下一致约定，可在 `resource/config/default.tres` 的 Inspector 中调整：

- 初始每色一块半径 64 的领土圆盘；这是首版拟合起点。
- 固定 216×208 逻辑格，每格面积 25。所有武器及护盾统一按每格 `2^(T / 120)` 点消耗涂色数值：开局 1 点，2 分钟 2 点，4 分钟 4 点，6 分钟 8 点，期间平滑增长。默认 `PaintCostPerArea = 0.04`、`PaintCostTimeScale = 120`（翻倍时间，局内秒）。经验系数 `0.004` / 面积 / 秒，与屏幕分辨率无关。
- 不足再涂一格的预算在遇到非己方区域时退出，并独立记录为 `PaintRemainder`，不虚计面积。
- 大球默认弹性反弹，避免反复碰撞耗散速度而使末局长时间滞留；质量/半径曲线独立于左侧弹珠。同阵营大球碰撞只做位置分离与反弹，不扣数值；数值下降来自沿路径涂色或敌方攻击。大球值达到 `BigBallNeutronThreshold = 1e9` 时永久坍缩：半径固定为 `BigBallNeutronRadius = 7`，引力加速度为 `NeutronGravityStrength × 密度 / 距离²`，封顶 `NeutronGravityMaxAcceleration`，对所有射弹与大球生效，星体自身跳过自引力。
- 射弹摧毁敌方护盾或大球时，只消耗目标剩余值，溢出值保留在射弹上继续向前；若目标未被摧毁，射弹照常消失。破盾后的溢出值可以继续命中后方据点。
- 护盾显示半径使用 `ShieldRadiusEaseSeconds`（默认 0.2 秒）指数缓动；缓动只作用于显示球壳，碰撞与伤害仍即时按护盾值计算。
- 狙击不再按时间失效：主体和碎片持续存在，直到涂色预算耗尽、命中护盾触发裂解或命中目标。默认裂成 8 片，散布角 1.4 弧度。狙击主体/碎片命中大球沿用射弹数值转移规则；击杀大球时同样保留剩余值继续飞行。
- 霰弹默认 24 发、基准扩散 24°；单发数值为本次兑换值均分，整波发射。每发额外叠加 `ShotgunAngleJitterDegrees = 2°` 的随机角度、`ShotgunSpawnSpread = 26` 的随机发射距离和 `ShotgunSpeedJitter = 0.12` 的速度抖动，避免整齐的一排。死亡弹也可兑换霰弹。
- 弹珠半径的时间影响由 `RadiusTimeMultiplier`（默认 1）缩放：它同时作用于随时间收缩的半径衰减和随时间增长的半径枢轴，0 表示时间不影响半径；质量的时间衰减不受该倍率影响。可在调试面板实时调整。
- 命中无盾据点后，射弹消失，大球反弹。复活后的后续命中重新查询新护盾。
- 亡语合并保留一个球 ID，从顶部发射；未获得池位的已赚取弹珠按初值 1 纳入亡语预算，无空位时继续排队。
- 终盘风暴将仍存活阵营的剩余机枪储量转为风暴，不额外创造火力；可关闭 `FinaleReserveStorm`。
- 参考图采用程序绘制与 Shader 重建；未承诺逐像素或隐藏数值公式完全一致。对局长度取决于种子和这些拟合参数，不设置强制淘汰、亡语超时或大球超时。

## 代码入口

- `src/Simulation/MatchSimulation.cs`：统一时钟、复活/淘汰、终盘与胜者。
- `PinballSimulation.cs` / `PinballGeometry.cs`：弹珠、移动能力栏和共用碰撞几何。
- `BattleSimulation.cs` / `AdvancedWeapons.cs` / `WeaponMotion.cs`：经济、六类能力、连续碰撞与有序结算。
- `TerritoryGrid.cs`：二维归属和固定面积计费。
- `src/Presentation/`：只读状态显示、粒子/拖尾、大球 Shader 与三类报告。
- `resource/scenes/`：主场景、弹珠盘、战场、两种球预制体、四角据点、报告界面。
- `resource/config/default.tres`：拟合参数；`resource/shaders/`：背景、领土与大球材质。

模拟采用固定 120 Hz 与显式种子。各攻击先推进到最早碰撞，重查改变后的实体/盾状态；并列按稳定实体 ID 排序。表现层不使用战斗随机源。领土纹理最高 10 Hz 上传，轨迹与粒子不影响逻辑步长。

## 验证与开发命令

```powershell
dotnet build Demo.csproj
$engine = 'E:/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64_console.exe'
$env:GODOT_MCP_RUNTIME = '0'
& $engine --headless --path . --audio-driver Dummy -- --self-test
& $engine --headless --path . --audio-driver Dummy -- --complete-match --seed=777
```

测试入口：

- `--self-test`：碰撞、基础战场、经济、先进能力、霰弹/中子星和终局回归。
- `--board-test`：盘面节点与碰撞几何一致性、弹珠按需实例化、回流释放、容量和重开回归（也包含在完整自检中）。
- `--advanced-test`：仅先进能力、霰弹与中子星测试，适合快速检查。
- `--complete-match --seed=N`：不注入作弊状态的自然完整对局，最多检查 3600 秒模拟时间；诊断上限只属于测试程序，游戏没有这个强制结束上限。报告写入 `.godot/completed-match-N.json`。
- `--capture --capture-seconds=90`：真实渲染截图到 `.godot/preview.png`。
- `--capture --capture-seconds=240 --capture-report=0`：自然结束后截取报告，0/1/2 对应三个标签页。
- `--capture --capture-seconds=1 --capture-animation --capture-neutron`：中子星坍缩与引力弯折射弹的 60 帧动画，输出到 `.godot/animation-neutron/`。
- `--capture --capture-seconds=1 --capture-animation --capture-shotgun`：四色霰弹的随机角度与前后错落弹幕，输出到 `.godot/animation-shotgun/`。
- `--capture --capture-seconds=2 --capture-debug`：打开调试面板并截图到 `.godot/preview.png`，用于检查全能力按钮与半径时间倍率控件。
- `--capture --capture-seconds=1 --capture-animation --capture-baffle`：升降挡板与过大球接触的显示/碰撞对齐检查，输出到 `.godot/animation-baffle/`。
- `--benchmark`：预推进 90 秒，暖机 30 帧后采样 300 帧，输出 `.godot/render-benchmark.json`。

正式运行保留原 Godot MCP 插件配置。验证时上述环境变量只关闭测试进程的插件服务。沙箱下的系统证书/Shader 缓存写入提示与游戏玩法无关；实际 D3D12 画面已检查。

最新验证结果和截图见 `.doc/implementation/`。旧 `stage-02.png`、`pinball-collision-fix.png` 是实现过程的历史快照。

## 视觉迭代（2026-11-12）

以本地 `detail-5.png`、`detail-720.png` 参考为基准调整：深灰金属盘面、稀疏网格、分层金属圆环和槽位读数框；按运动方向展开的双色弹珠拖尾；明亮领土渐变与径向细丝；独立护盾球壳 Shader、涡流细丝与发光经验轨道；暗心亮边的大球。默认隐藏中央 HUD，H 键展开，底部保留提示。所有效果只读取模拟状态。

仍有差距：固定 216×208 归属网格在近看时仍有阶梯边缘，参考视频的百万像素流场与长时粒子轨迹尚未等同实现。本轮没有通过改变领土计费网格或战斗规则来掩盖这些差异。

### 第二轮视觉迭代

领土纹理改用四通道阵营覆盖率，插值后重建边界与配色，减轻方块高光和彩色脏边；增加抗摩尔纹细丝、缓慢流动的明暗层次和微光粒子。逻辑领土仍为 216×208，视觉平滑不增加计费面积。普通射弹也记录 1.4 秒淡出轨迹，固定步采样、直线合并、8192 段上限、16 组批量绘制；重置/换种子清空历史。四角护盾和机枪读数分别置于核心上下方。领土纹理按真实时间约 14Hz 上传，倍速不会放大上传频率。

第二轮截图见 `.doc/implementation/visual-v2-90s.png` 和 `visual-v2-30s.png`；验证见 `visual-v2-validation.md`。

### 倍率槽入口调整

按参考方向缩窄外侧高倍率入口：每侧 ×8 / ×4 / ×2 的水平入口宽度为 60 / 84 / 112（逻辑单位）。分隔墙 x=90、174，中央壁起点 x=286；右侧镜像，倍率圆环重新居中，绘制和碰撞继续共用几何。改变入口会改变同种子的后续轨迹。本次 110 项自检通过，600 秒弹珠模拟 881 次倍率、132 次兑换；联动重放 shots=1181、territory=44928、upgrades=4。截图：`.doc/implementation/pocket-widths.png`。

### 实体隔断修正

倍率区之间改为 18 单位宽的实体障碍，具有斜顶、左右侧面，并与下方底座连为同一多边形。碰撞直接取该多边形外轮廓。净入口宽度更新为 ×8=60、×4=66、×2=94，左右镜像，槽位重新居中。112 项检查通过，含隔断两侧及斜顶碰撞；600 秒 811 次倍率、158 次兑换。截图 `.doc/implementation/solid-dividers.png`。

### 开局护盾与第三轮领土视觉

四个阵营开局各有 20,000,000 护盾；重置及换种子重新开局同样生效。`InitialShield` 可在默认配置资源中调整；开局赠送值不计入兑换火力。护盾改为通透暗心、明亮球壳、高光与漂浮微粒，视觉球壳半径对齐实际碰撞半径。领土加入复合流动纹理和缓慢漂移的微光。

构建 0 警告、0 错误，115 项自检通过，新增四阵营初值、重置恢复、不虚增兑换统计检查。原先依赖无盾环境的碰撞测试显式使用 InitialShield=0。实际检查 1 秒开局及 90 秒激战截图：`.doc/implementation/shield-20m-opening.png`、`territory-v3-90s.png`。既有自然对局时间记录早于本次规则调整，不再代表当前参数。

### 帧率排查与优化（2026-11-12）

### 护盾半径曲线调整（2026-11-20）

护盾半径曲线由 `18 + 6 × log2(1 + 护盾值)` 改为 `10 + 8 × log2(1 + 护盾值)`，上限由 128 提高到 140。低护盾值时半径更小（护盾 1 时 24 → 18），高护盾值时更大（护盾 1,000 时 77.8 → 89.7，护盾 10,000 时 97.7 → 116.3）；初始 20,000,000 护盾的显示半径由 128 变为 140，上下据点护盾恰好触及画面上下边缘。护盾值与碰撞/显示半径继续同步。

### 护盾半径曲线再调整（2026-11-20）

护盾半径曲线改为 `-5.06739 + 6.06739 × log2(1 + 护盾值)`，上限仍为 140。护盾值为 1 时半径由 18 降为 1；与上一版曲线（`18 + 6 × log2(1 + 护盾值)`，上限 128）的交点改到护盾值 4,000,000，交点半径 128。低于 4M 时半径小于上一版，高于 4M 时更大，约 15.76M 达到上限 140；极小护盾值的半径按 0 处理。

### 护盾封顶值与最大半径调整（2026-11-20）

保留「护盾 1 → 半径 1」「与上一版曲线在 4,000,000 护盾值相交（半径 128）」，半径曲线改为二次对数形式 `r = -1.396865 + 2.229502 × L + 0.1673627 × L²`（`L = log2(1 + 护盾值)`）。封顶阈值由约 15.76M 提高到 **4,000,000,000（4B）**，最大半径由 140 提高到 **240**。示例：10,000 护盾约 57.8、1,000,000 约 109.5、100,000,000 约 176.1、1B 约 214.9。半径超过约 140 后，上下据点的护盾会超出画面上下边缘。
